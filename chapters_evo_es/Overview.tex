\chapter{Descripción y contenido del paquete}
IV-Evo es un indicador de PHOL-LABS Kft con ESP32-C3, pantalla IPS de 160\,\texttimes\,80 píxeles y frontal de vidrio templado. Este manual cubre la versión Golf/Jetta II. La fuente también menciona variantes para Golf, Jetta, Polo, Audi y LADA; compruebe la variante física antes de instalarla.

Admite Wi-Fi, Bluetooth LE, aplicaciones y scripts de sensores Lua, imágenes JPG/PNG/BMP y animación sencilla 2D y 3D. La aplicación controla la pantalla y la interacción; el script del sensor proporciona los valores medidos. La aplicación, el sensor y la calibración deben corresponderse.

La lista de contenido incluye un indicador de tipo botón y un conector KF2510 con cables. No incluye sensores, controladores externos ni Digifiz Next. Aunque un párrafo comercial menciona un programador, este no figura en la lista explícita del paquete.
